## Why Aicrion QRCode?

- 🧱 Modern architecture: interfaces, immutable value objects, enums (PHP 8.2+)
- 🖼️ Multiple output formats: PNG, SVG, EPS, WEBP
- 📥 Multiple input sources for reading: file path, binary string, Base64, URL, GD image, stream resource
- 🎨 Custom colors, size, margin, error correction level, embedded logo, and labels
- 🧪 Fully unit and feature tested with PHPUnit
- 📦 Simple Composer installation, zero configuration required
